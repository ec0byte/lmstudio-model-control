# Contributing to lmc

Thank you for your interest in contributing! This document outlines how to set up your development environment and submit contributions.

## Getting Started

### Prerequisites

- Python 3.9+
- pip (Python package manager)

### Installation

1. Clone the repository:
   `ash
   git clone https://github.com/ec0byte/lmstudio-model-control.git
   cd lmstudio-model-control
   `

2. Install dependencies:
   `ash
   pip install -e .
   `

## Development

Make your changes, test them locally, and submit a pull request when ready.

For more information on the project structure and how to contribute, please see the [README](README.md).
